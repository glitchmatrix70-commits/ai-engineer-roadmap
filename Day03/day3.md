# Day 3 – Git & GitHub | Interview Questions & Answers

---

## Question 1

### Difference between Git and GitHub

| Git | GitHub |
|------|--------|
| Git is a distributed version control system used to track changes in code. | GitHub is a cloud platform that hosts Git repositories and enables collaboration. |
| It works locally on your computer. | It works online and stores Git repositories in the cloud. |
| It helps manage versions of your project. | It helps teams collaborate, review code, and manage projects. |

**Real-life Example:**  
Git is like **Microsoft Word's "Track Changes"**, while GitHub is like **Google Drive**, where you store and collaborate on your documents.

---

## Question 2

### What does `git init` do?

**Interview Answer (1–2 lines):**  
`git init` initializes a new Git repository by creating a hidden **`.git`** folder that stores the project's version history and configuration.

**Real-life Example:**  
Like buying a new diary before writing your first entry—the diary is ready to record every change.

---

## Question 3

### Difference between `git add` and `git commit`

| `git add` | `git commit` |
|------------|--------------|
| Stages changes that you want to save. | Saves the staged changes as a permanent snapshot in Git history. |
| Changes are not yet stored in history. | Creates a new version of the project. |

**Real-life Example:**  
`git add` is like selecting photos for an album, while `git commit` is like printing and permanently placing those photos into the album.

---

## Question 4

### Why do companies use branches?

**Interview Answer (1–2 lines):**  
Companies use branches so multiple developers can work on different features or bug fixes independently without affecting the main codebase.

**Real-life Example:**  
Like different chefs preparing different dishes in separate kitchens before combining them into one buffet.

---

## Question 5

### Difference between `git clone` and `git pull`

| `git clone` | `git pull` |
|--------------|------------|
| Downloads a repository to your computer for the first time. | Downloads the latest changes for a repository you already have. |
| Creates a new local copy of the repository. | Updates the existing local repository. |

**Real-life Example:**  
`git clone` is like buying a new copy of a book, while `git pull` is like receiving updated pages for the book you already own.

---

## Question 6

### What happens when you run `git push`?

**Interview Answer (1–2 lines):**  
`git push` uploads your local commits to the remote repository (such as GitHub), allowing others to access your latest changes.

**Real-life Example:**  
Like submitting your completed assignment to the college portal so your teacher and teammates can see it.

---

# Quick Revision

- **Git** → Version control system that tracks code changes.
- **GitHub** → Cloud platform for hosting Git repositories.
- **`git init`** → Creates a new Git repository.
- **`git add`** → Stages changes for the next commit.
- **`git commit`** → Saves a snapshot of staged changes.
- **Branches** → Allow parallel development without affecting the main branch.
- **`git clone`** → Download a repository for the first time.
- **`git pull`** → Update your local repository with the latest changes.
- **`git push`** → Upload local commits to GitHub.
